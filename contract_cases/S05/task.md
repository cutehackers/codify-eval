$codify Specify. 사용자는 혼자 쓰는 메모 앱에서 삭제 버튼으로 로컬 메모를 삭제한다. 로그인, 서버, 동기화, 복원 기능, 마이그레이션은 범위 밖이다. 각 메모는 기존 앱에서 발급한 고유 ID를 가진다. 존재하지 않는 ID 삭제는 아무 변화 없이 종료한다. 연속 삭제 요청도 같은 결과이며 메모 외 데이터에 부작용이 없어야 한다. 성공은 해당 ID가 목록에서 사라진 것으로 확인한다. 실패하면 메모를 보존하고 오류를 표시한다. 성능 수치는 요구하지 않는다. INT-01은 불필요한 메모 제거, GOAL-01은 삭제 후 목록에서 메모가 사라지는 결과다. 아직 구현된 코드는 없으며 이번 요청은 문서만 만든다. 삭제 전 확인 대화상자를 선택한다. 취소하면 원본은 보존하고 확인하면 삭제한다. 이 결정은 명시적으로 수락한다. 다른 제품 결정은 없다. 결정의 대안은 확인 없이 즉시 삭제이며, 실수로 삭제하는 것을 막기 위해 확인을 선택했다. 요구사항을 Hardened까지 정리하되 부모 계약은 내가 요청한 대로 Proposed로 유지하라. 부모 승인을 다시 묻지 말고 슬라이스나 구현은 만들지 말라.
