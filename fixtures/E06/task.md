# E06

교체 가능한 LocalStore를 사용해 입력 초안을 저장하고 위젯 재생성 시 불러오세요. 새 저장소의 null은 빈 초안을 의미합니다. write가 완료된 뒤에만 "저장됨"을 표시하고 실패 시 "저장 실패"를 표시하세요. read 실패 시 "불러오기 실패"를 표시하세요. 입력은 여러 줄을 지원하고 저장소의 내용은 공백과 줄바꿈을 포함해 입력 그대로 보존합니다. 외부 provider나 실제 디스크 접근은 필요 없습니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
