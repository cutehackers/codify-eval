# E05

기록 목록에서 각 항목을 누르면 해당 ID의 상세 화면으로 이동하도록 구현하세요. 상세에는 제목과 본문을 표시하고 뒤로 가기로 목록으로 돌아옵니다. 존재하지 않는 ID는 제목 "찾을 수 없음", 본문 "기록이 없습니다"를 표시하세요. EntryDetail(repository:, id:)를 공개 위젯으로 제공하세요. 모델과 저장소는 기존 모듈을 사용하세요.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
