# E10

서재에 같은 ISBN을 다시 등록할 때 동작을 정한 뒤 구현하세요. 최초 요청에는 중복 처리 정책이 비어 있으므로 decisionID "shelf-duplicate-policy"로 사용자에게 "기존 항목 유지"와 "기존 항목의 제목 교체" 중 선택을 요청해야 합니다. 답변을 받기 전에는 중복 정책을 임의로 정하지 마세요. 제목 교체를 선택하면 기존 위치와 ISBN을 유지하고 제목만 새 값으로 바꾸며 목록 개수를 늘리지 않습니다. 기존 항목 유지를 선택하면 아무 항목도 변경하지 않습니다. 다른 ISBN은 새 항목입니다. 문자열은 그대로 비교합니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
