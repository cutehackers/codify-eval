# H02

상품 목록과 장바구니 요약을 연결하세요. 상품 버튼을 누를 때마다 SKU별 수량이 1 증가하며 요약에 상품명 x수량과 센트 단위 합계를 즉시 표시합니다. 알 수 없는 SKU를 Basket.add에 넘기면 무시합니다. 동일 이름의 다른 SKU는 별도 상품입니다. Basket을 유지한 채 앱을 다시 생성해도 수량이 보존되어야 합니다. 기존 catalog/summary/basket 모듈을 활용하세요.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
