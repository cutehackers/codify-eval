# E08

RemoteService와 NewsAdapter를 사용하는 소식 화면에서 초기 로딩과 실패 후 재시도를 완성하세요. 로딩 중 "불러오는 중", 실패 시 "소식을 불러오지 못했습니다", 성공 빈 목록은 "소식 없음"입니다. 재시도 버튼은 로딩 중 비활성화하며 한 번만 요청합니다. 성공 시 최신 항목을 표시하고 오류를 지웁니다. 위젯 제거 후 응답이 와도 예외가 없어야 합니다. 실제 네트워크 호출은 범위 밖입니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
