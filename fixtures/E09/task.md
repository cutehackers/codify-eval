# E09

검색 컨트롤러의 요청 경합을 고치세요. 여러 검색을 연속 실행하면 마지막 시작한 요청만 results/error/busy를 갱신합니다. 이전 요청 성공과 실패는 모두 무시합니다. 새 검색 시작 시 error를 지우고 busy=true를 알립니다. 마지막 요청 실패 후 같은 쿼리 재시도도 가능해야 합니다. dispose 후 응답은 무시하고 이후 search도 서비스 호출 없이 종료합니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
