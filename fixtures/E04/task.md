# E04

이름 저장 폼을 완성하세요. 공백만 입력하면 "이름을 입력하세요"를 표시하고 save를 호출하지 않습니다. 이름은 trim 후 전달합니다. 저장 중 "저장 중"을 표시하고 저장 버튼을 비활성화합니다. 성공은 "저장 완료", 예외는 "저장 실패. 다시 시도하세요"로 표시하고 재시도가 가능해야 합니다. 저장 중 위젯이 제거되어도 예외가 발생하지 않아야 합니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
