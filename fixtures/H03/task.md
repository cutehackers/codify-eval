# H03

상태 화면과 JSON 어댑터의 오류 복구를 구현하세요. StatusAdapter.fetch는 status가 비어 있지 않은 문자열인 JSON 객체만 받아들이며 잘못된 응답은 FormatException입니다. 네트워크 예외나 JSON 오류는 화면에서 "상태 확인 실패"로 표시합니다. 초기 요청 및 새로고침 동안 "확인 중"과 비활성화된 버튼을 표시하고 성공 시 서버의 원문 상태를 표시합니다. 실패 후 새로고침으로 복구할 수 있어야 합니다.

허용: lib/ 내부 구현 변경과 새로운 test/ 회귀 테스트 추가. 보호: pubspec.yaml, 사전 존재하는 사용자 파일. 공개 클래스와 생성자 계약을 유지하세요. 기존 테스트나 검증 도구를 약화해서 통과시키지 마세요.
