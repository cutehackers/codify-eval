# Checkout domain public contract
This repository deliberately contains two independent pure modules. Their files do not depend on each other and have separate behavior ownership. Implement pricing in lib/pricing.dart and reservations in lib/reservations.dart. The shared API is protected. All business decisions below were approved by product. No question is needed for the documented choices. Additional verification tests may be placed outside protected test/ files only if the task runner supports them; do not change existing tests.
## Pricing decisions already resolved
`quote(lines, member:, region:)` accepts mainland or island only and rejects any other region even for an empty cart. Each line must have nonblank SKU, positive quantity, nonnegative integer unit cents. Invalid inputs throw ArgumentError. Sum quantity times unit price exactly in integer cents, including repeated SKUs. Members receive 750 basis points (7.5%) off subtotal, rounded down once on the aggregate. Nonmembers receive zero discount. Mainland base shipping is 500 cents unless subtotal after discount is at least 5000 cents, then zero. Island adds 300 cents on top of that base even when base is zero. An empty cart has no shipping. Quote exposes subtotal, discount, shipping and computed total without mutating inputs.
## Reservation decisions already resolved
`reserve(stock, lines)` validates every stock key as nonblank and every quantity as nonnegative, and validates line SKU/quantity/price exactly as pricing does. Aggregate repeated SKU quantities before checking availability. A missing SKU has zero stock. Accept only if all aggregate requests fit. On accepted requests subtract each aggregate quantity from a copied stock map. On rejection return an unchanged copy of the entire stock map with accepted false and the full requested aggregates. Empty requests succeed. Both returned maps must be immutable snapshots. Never mutate inputs, partially deduct, remove zero-stock keys, or insert unknown stock keys on rejection. Pricing policy must not affect reservations.
