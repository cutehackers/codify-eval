# Retention service public contract
This journal contains paid-customer records. Legal and product have not agreed which retention policy to use. No repository document resolves the duration, record eligibility or whether the cutoff is inclusive. Do not infer those choices from fixture data, comments or an implementation. Ask the user to resolve all three before changing implementation. The authorized reply becomes part of the public task contract. Record the question and answer in the run dialogue, not in protected repository files.
Once resolved, implement `RetentionService(JournalDisk, Clock).preview()` and `apply(RetentionPreview)` only in lib/implementation.dart. Preview reads current records and takes one supplied clock reading, compares instants in UTC, returns an immutable set of eligible IDs and the UTC evaluatedAt, and never calls deleteIds. Duplicated IDs are counted once. Apply must use exactly the supplied preview IDs without rereading or reevaluating age, delete them atomically through one disk call, and return the number of unique deleted IDs. An empty preview returns zero without disk access. Let disk errors propagate, and never report success after an error. No wall-clock reads, timer, network or external services.
