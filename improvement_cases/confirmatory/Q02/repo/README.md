# Draft edit public contract
`OwnedDraftStore(Session, DraftDisk).save(id, title, expectedRevision)` edits an existing private draft. Authenticate before any disk access. A null session returns denied. After authentication validate id against ASCII `[A-Za-z0-9_-]{1,64}`, nonnegative revision, nonblank trimmed title, at most 120 Unicode code points in the original title, and no CR or LF. Invalid arguments return invalid without disk access. Do not create missing drafts. Missing drafts and drafts owned by another principal produce the identical denied result. Only the owner may edit. Revision mismatch returns conflict with no write. Persist the trimmed title while preserving stored id and owner, incrementing revision once. Use the disk's atomic compare-and-replace and handle false as conflict. Never mutate a retrieved record.
Exact public results: saved / "Saved", denied / "Access denied", invalid / "Invalid draft", conflict / "Draft changed", unavailable / "Draft unavailable". Only saved includes a draft. Catch errors from session, read and replace without exposing exception strings, IDs, titles, paths or stack details. Failure never performs an additional write or retry. Dependencies may be hostile or fail, and successful persistence is only confirmed by true from replace.
