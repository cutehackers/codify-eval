# Public feed contract
`FeedController(FeedTransport, FeedCache)` exposes immutable `entries`, `restore()` and `refresh()`.
Restore accepts legacy JSON arrays and version 2 objects with `version: 2` and `entries` arrays. Each row has string id/title/updatedAt (ISO timestamp). Invalid or unknown payloads and cache-read errors preserve the current view, never partially restore, and never write. Normalize UTC dates. Deduplicate IDs by newest updatedAt, with the last occurrence winning equal timestamps. Sort newest first then ID ascending.
Refresh starts a new generation, fetches all pages beginning at null, treats any repeated non-null next cursor as failure, and commits only a complete success. Empty final results clear the view. Failed transport or cache write preserves the prior view. Success writes version 2 JSON with normalized rows before changing the view. A generation overtaken while fetching must return superseded and must never write or update the view. If overtaken during an already started cache write it must not update the view when that write finishes. Storage guarantees each write is atomic but does not offer cancellation. Results expose immutable snapshots. Dependencies are injected and may complete in any order.
