# Native 기록 형식 보완 v3.6.1

> 보존 상태: 2026-10-14 사용자 요청으로 원본 실행 로그·임시 실행 코드·보존 압축본을 삭제했다. 이 문서의 과거 경로·해시는 당시 기록이며, 현재 보존 자료는 README와 최종 보존 기록을 기준으로 확인한다.

S03 첫 새 실행에서 모델은 고정 답변을 실제 읽었지만, 수신 기록이 `message` 대신 `content` 블록에 저장되어 채점기가 전달 연결을 확인하지 못했다. 부모 호출의 암호화된 값과 자식의 `content.encrypted_content` 값은 같고, 실제 읽기 반환값은 고정 원문 UTF-8 hash와 일치한다. 이 사건은 스펙 6절의 수집·분류 오류 보완으로 처리하며 모델을 다시 실행하지 않는다.

**보완1:** `tools/dialogue_schema.py`는 native 기록을 복사한 메모리 뷰에서만 수신 값을 기존 `message` 필드로 전달한다. 원본 파일, 요청, 답변 파일, 모델 산출물, 행동 기준과 frozen-core-v3.6 revision2는 바꾸지 않는다. 암호화된 본문을 복호화하거나 정확한 안내 문장을 확인했다고 주장하지 않는다.

**보완2:** 기존 표현과 현재 `content` 표현에 같은 전달·순서·모델·바이트·컨테이너·완전한 반환 증거 기준을 적용한다. 애매한 블록, 중복 암호화 값, 상충한 표현은 거부한다. 수정 전 코드가 남긴 오류 grade와 audit은 원본 hash로 보존한 뒤 같은 산출물을 한 번 재채점한다. 이미 확인된 성능 실패를 지우기 위한 재실행이나 추가 모델 안내는 허용하지 않는다.

**보완3:** 독립 검토와 검사 후 supplemental manifest를 고정한다. 어댑터와 기존 도구·스펙·core의 정확한 hash를 채점 전에 확인하고, audit에 어댑터·등록 hash와 변환한 원본 필드의 hash를 기록한다. 새 고정 답변 실행의 채점에도 동일하게 적용한다. 실행 명령은 `python3 tools/dialogue_schema.py RUN_ID`다. 최종 보고는 원래 수집 오류와 후속 판정을 함께 공개한다.

기록 형식 보완의 검사 통과는 실제 소프트웨어 작성 평가 완료를 의미하지 않는다.
