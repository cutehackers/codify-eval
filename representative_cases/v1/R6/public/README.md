# Shipment manifest import
Implement a standard-library Python 3.11+ manifest import feature. Keep interfaces stable. Editable files are `manifest_parser.py`, `batch_processor.py`, and `manifest.py`. `models.py` and smoke tests are fixed.

`parse_line(text, line_number)` returns the frozen `LineItem` model or raises `ManifestError(code, message)`. CSV records have exactly four fields: order ID, SKU, quantity, unit price. CSV quoting follows `csv.reader(..., strict=True)` semantics. A single trailing LF or CRLF physical line terminator is allowed. Embedded newlines are forbidden. Trim surrounding whitespace in each field. IDs must match ASCII `[A-Za-z0-9_-]{1,32}`. Quantity must consist of ASCII digits and be in 1..10000. Price must match ASCII digits followed by a dot and exactly two ASCII digits, with value 0.00..1000000.00 inclusive. Preserve Decimal precision. Error codes are `csv` (syntax/newline), `fields` (field count), `order_id`, `sku`, `quantity`, `price`, checked in that order. Messages are nonempty human-readable text, exact wording is flexible.

`process_lines(lines, parser=parse_line)` accepts any iterable of strings and calls the supplied parser for each nonblank physical line, with its 1-based position including blank lines. It returns `BatchResult`: accepted items in input order, row errors in input order, and Decimal totals per order (quantity times price). A parser `ManifestError` becomes `RowError` and processing continues. Other exceptions propagate. Do not parse twice. Skip whitespace-only lines. Reject duplicate `(order_id, sku)` pairs among accepted items with `duplicate` errors. A rejected row does not reserve a duplicate key. Preserve original source text, including newline, in `RowError.text`. Do not mutate inputs. Every invocation has independent duplicate/totals state.

`summarize(lines)` integrates the default parser and processor and returns a JSON-serializable dictionary with exactly `accepted_count`, `errors`, and `orders`. Errors are dictionaries with `line_number`, `code`, and `message`. Orders are dictionaries with `order_id` and `total`, sorted by ASCII order ID. Format total as a fixed two-decimal string. Empty input returns zero, [], [].
